# Movie Streaming Application

This repository contains the source code for a full-stack movie streaming application. It uses a monorepo architecture, housing both the frontend client and the backend API within the same repository.

## Technologies Used

### Backend
*   **Go (Golang) v1.23**: The core programming language used for the backend API.

### Frontend
*   **Angular v21**: The framework used for building the user interface.
*   **Tailwind CSS v3**: A utility-first CSS framework for rapid and custom UI styling.
*   **Spartan UI**: A collection of accessible, un-styled Angular UI primitives built on top of Tailwind CSS.

### Infrastructure
*   **MongoDB**: The NoSQL database used for data persistence.
*   **Docker Compose**: Used to manage and run the MongoDB container locally.
